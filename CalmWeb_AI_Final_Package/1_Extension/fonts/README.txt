Optional: real OpenDyslexic font

CalmWeb's "Dyslexia-friendly" font uses Comic Sans MS / Verdana until you add OpenDyslexic.
To use the real font:
1. Download it free from https://opendyslexic.org
2. Copy the file OpenDyslexic-Regular.otf into this "fonts" folder.
3. Go to chrome://extensions and click the reload arrow on CalmWeb AI.
