CalmWeb AI - Final Project Package
Team: Sreecharan Javalkar, Kassim Moutary, Ryan, Aasrith Jangala

1_Extension/CalmWeb_AI_v3.1.zip
   The Chrome extension. Extract it, go to chrome://extensions, turn on Developer mode,
   click Load unpacked, and pick the extracted folder. No Python needed.

2_Training_Code/CalmWeb_AI_training.zip
   Python code that trained and tested the AI model (SMS Spam Collection + BBC News,
   TF-IDF -> truncated SVD dimensionality reduction -> logistic regression), results and charts.

3_Model_Card/CalmWeb_AI_Model_Card.pdf
   The Mark Cuban Foundation model card, filled in with our real test results (98% accuracy).

4_Charts_and_Screenshots/
   Images for the "Progress so far" slide.

The full project write-up (goal, AI use, ethics check, needs and challenges, next steps,
gap-busting plan, 1-2 minute script, Q&A) is in the "CalmWeb AI - Final Project Document" doc.
