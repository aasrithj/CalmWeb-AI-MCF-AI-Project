# CalmWeb-AI-MCF-AI-Project

This is the project repository for the 2026 Richmond Mark Cuban AI Foundation Launchpad Project, involving the team member Aasrith Jangala (myself).

# overview

CalmWeb AI is an accessibility-focused browser extension designed to transform visually overwhelming websites into calmer, more readable, distraction-free learning environments. Built with the goal of supporting neurodivergent learners, CalmWeb AI combines artificial intelligence, natural language processing, and webpage analysis to make digital learning more accessible.

# installation (no Python needed)

Download the packages by navigating to this GitHub repository and clicking the "<> Code" dropdown menu, click "Download ZIP," extract the ZIP via File Explorer (right-click > Extract All), open chrome://extensions, and turn on "Developer mode." Then, click "Load unpacked," double-click the extracted "CalmWeb_AI_Final_Package" folder, and select the "1_Extension" folder (ensure it contains the `manifest.json` file). Refresh any tabs that are open in order to see CalmWeb AI in real time by selecting the puzzle piece icon in your browser and enabling CalmWeb AI. ***Please note that CalmWeb AI fails to function on certain websites due to underlying system errors and a slightly inaccurate AI backend, which will be fixed soon.***
